# 體態階段判斷

## 先增肌還是先減脂？

### 決策樹

```
體脂率估算
  ├─ 男 >20% 或 女 >28% → 先減脂
  ├─ 男 <12% 或 女 <18% → 先增肌
  └─ 中間值 → 看目標
       ├─ 想看起來更壯 → 增肌
       ├─ 想看起來更瘦 → 減脂
       └─ 不確定 / 新手 → body recomp (維持熱量 + 重訓)
```

### 為什麼不建議高體脂直接增肌

- 胰島素敏感度下降 → 盈餘更容易轉化為脂肪
- 荷爾蒙環境不利（雌激素↑、睪固酮↓）
- 體脂越高，增肌效率越低（P-ratio 偏差）

### 為什麼不建議太瘦時減脂

- 已無足夠脂肪可減
- 肌肉量不足 → 減完沒有好看的線條
- 基礎代謝太低 → 熱量無法再降

## 體脂率目視估算參考

| 體脂率 (男) | 外觀特徵 |
|------------|---------|
| 8-10% | 腹肌六塊清晰、血管浮現、臉頰凹陷 |
| 12-15% | 腹肌可見但不分明、腰線明顯 |
| 16-20% | 隱約腹肌、稍有小腹 |
| 22-25% | 腹肌消失、腰腹明顯圓潤 |
| >25% | 肚子明顯突出 |

| 體脂率 (女) | 外觀特徵 |
|------------|---------|
| 15-18% | 腹肌可見、手臂線條分明（選手等級） |
| 20-23% | 身材緊實、有線條 |
| 24-28% | 健康標準、曲線明顯 |
| 30-35% | 微胖、腰臀比↑ |
| >35% | 明顯過重 |

## 新手特殊策略

### 新手紅利期（前 6-12 個月）

- 可以同時增肌減脂（body recomposition）
- 條件：維持熱量或微赤字 + 高蛋白 + 系統性重訓
- 不需要刻意選擇增/減，兩者同時發生
- 紅利期結束的信號：力量進步明顯放緩

### 新手建議優先序

1. 學會正確動作模式（蹲推拉）
2. 建立訓練習慣（每週 3 次以上）
3. 蛋白質攝取達標（1.6 g/kg）
4. 再來考慮精確的增/減週期

## 增減脂循環（Bulk/Cut Cycle）

### 標準循環

```
增肌期 (3-6 個月)
  → 體脂到上限 (男 18% / 女 28%) 或目標體重
  → 轉減脂

減脂期 (2-3 個月)
  → 體脂到下限 (男 10-12% / 女 18-22%) 或目標
  → 轉維持

維持期 (2-4 週)
  → 穩定新體重、恢復代謝
  → 下一個循環
```

### 切換時機信號

開始減脂：
- 體脂超過舒適上限
- 衣服開始緊
- 增肌期超過 6 個月

開始增肌：
- 體脂到理想下限
- 力量明顯下降
- 減脂期超過 3 個月

## 使用者資料不足時的提問順序

如果使用者沒提供完整資訊，按以下優先序問：

1. 身高體重（算 BMI 粗估）
2. 目前體態自述 / 照片描述（有無腹肌、腰圍）
3. 訓練經驗（完全新手 / 有基礎 / 進階）
4. 目標（想變壯 / 想變瘦 / 想健康）
5. 每週可訓練天數

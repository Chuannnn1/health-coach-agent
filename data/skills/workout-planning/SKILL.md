# 訓練規劃

## 分化方式

### 3 天 / 週 — Push / Pull / Legs

- Day A（Push 推）：胸、肩、三頭
- Day B（Pull 拉）：背、二頭
- Day C（Legs 腿）：股四、臀、腿後、小腿

### 4 天 / 週 — Upper / Lower x 2

- Day A — Upper（力量）
- Day B — Lower（力量）
- Day C — Upper（量訓）
- Day D — Lower（量訓）

### 5 天 / 週 — Bro Split

- 胸 / 背 / 腿 / 肩 / 手臂（不建議新手）

## 組數 × 次數

| 目標 | 主要重量訓練 | 次數 | 組間休息 |
|------|------------|------|---------|
| 增肌 | 70-80% 1RM | 6-12 | 90-120 秒 |
| 減脂 | 65-75% 1RM | 10-15 | 60-90 秒 |
| 力量 | 85-95% 1RM | 1-5 | 3-5 分鐘 |

## 漸進性超負荷

- 每週嘗試小幅增加：重量 +2.5%、次數 +1、組數 +1（擇一）
- 卡關時優先檢查睡眠 / 蛋白質 / 訓練量

## 注意事項

- 任何疼痛先停練、評估姿勢
- 大重量複合動作優先（蹲推拉硬舉）
- 暖身：5-10 分鐘輕有氧 + 動態伸展 + 訓練動作空槓
